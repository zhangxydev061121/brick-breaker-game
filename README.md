# brick-breaker-game
A simple 2D brick breaker game made with Godot 4.

## Project Introduction
This is a classic breakout game. Player controls the paddle with A/D keys to bounce the ball and destroy bricks.
Made for learning game loop, collision detection and component pattern from *Game Programming Patterns*.

## Features
- A/D keys to move paddle
- Ball physics & bounce
- Brick destroy logic
- Score system

## Tech
Engine: Godot 4
Script: GDScript
